PASSO A PASSO DE COMO CLONAR MEU PROJETO:
1- clique no botão CODE e copie o link;
2- vá ao terminal e abra na pasta que deseja colocar o projeto (ex: cd Documents/Projeto);
3- execute o comando GIT CLONE e coloque o link que vc tinha copiado anteriormente (ex: git clone https://github.com/pipipopo);
4- depois da clonagem, é só entrar na pasta do repositorio (ex: cd repositorio).
